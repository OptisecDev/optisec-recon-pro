# requirements.txt because these tools hard-pin their dependencies with ==,
# which would otherwise dictate the app's own versions of shared packages.
#
# theHarvester is not on PyPI (the pypi package is a stub), so it is installed
# from GitHub, pinned to an exact commit rather than a tag or branch:
#   b9ec3bf — requires-python >=3.12 (matches the python:3.12-slim base image)
#   and pulls aiohttp==3.14.3 / ujson==5.13.0, which fix the advisories that
#   affected the 4.11.1 tag's pins. The upstream dev branch has since moved to
#   requires-python >=3.14, so do not unpin this to a branch ref.
